# Funds - Personal Finance Tracker

A comprehensive personal finance tracker built with [T3 Stack](https://create.t3.gg/) — Next.js, TypeScript, and Tailwind CSS — with PocketBase as the backend.

## Getting Started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Tech Stack

- [Next.js](https://nextjs.org) (App Router)
- [TypeScript](https://typescriptlang.org) (Strict Mode)
- [Tailwind CSS](https://tailwindcss.com)
- [PocketBase](https://pocketbase.io) (Auth, Database, Real-time)
